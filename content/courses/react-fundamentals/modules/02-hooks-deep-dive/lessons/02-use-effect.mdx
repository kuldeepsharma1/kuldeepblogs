# useEffect — Side Effects

The `useEffect` hook lets you synchronize a component with an external system — APIs, DOM manipulation, timers, subscriptions, and more.

## Basic Usage

```jsx
import { useState, useEffect } from 'react';

function DocumentTitle({ title }) {
  useEffect(() => {
    document.title = title;
  }, [title]);

  return <h1>{title}</h1>;
}
```

## The Dependency Array

The dependency array controls when the effect re-runs:

```jsx
// Runs after every render
useEffect(() => { /* ... */ });

// Runs only on mount (and cleanup on unmount)
useEffect(() => { /* ... */ }, []);

// Runs when `count` or `name` changes
useEffect(() => { /* ... */ }, [count, name]);
```

## Cleanup Function

Return a function from your effect to clean up:

```jsx
useEffect(() => {
  const handler = (e) => console.log(e.key);
  window.addEventListener('keydown', handler);

  // Cleanup: runs before the next effect and on unmount
  return () => window.removeEventListener('keydown', handler);
}, []);
```

<Callout type="tip">
  Always clean up subscriptions, timers, and event listeners to prevent memory leaks.
</Callout>

## Data Fetching

```jsx
function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    let cancelled = false;

    async function fetchUser() {
      setLoading(true);
      const res = await fetch(\`/api/users/\${userId}\`);
      const data = await res.json();
      if (!cancelled) {
        setUser(data);
        setLoading(false);
      }
    }

    fetchUser();
    return () => { cancelled = true; };
  }, [userId]);

  if (loading) return <p>Loading...</p>;
  return <h1>{user?.name}</h1>;
}
```

## Key Takeaways

- `useEffect` runs after render, not during
- The dependency array controls re-execution
- Always return a cleanup function for subscriptions
- Use the abort pattern for async effects
