# useState — Managing State

The `useState` hook is the most fundamental hook in React. It lets you add state to functional components.

## Basic Usage

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}
```

`useState` takes an **initial value** and returns an **array** with two elements:
1. The current state value
2. A function to update it

## Functional Updates

When the next state depends on the previous state, use a **functional update**:

```jsx
// ❌ Can be stale
setCount(count + 1);

// ✅ Always uses the latest state
setCount(prevCount => prevCount + 1);
```

<Callout type="warning">
  State updates are asynchronous. React batches them for performance. If you read state immediately after setting it, you'll get the old value.
</Callout>

## Objects and Arrays as State

For complex state, you need to create new references:

```jsx
const [user, setUser] = useState({ name: 'Alice', age: 25 });

// ✅ Spread to create a new object
setUser(prev => ({ ...prev, age: 26 }));

// ❌ Mutating the existing object won't trigger a re-render
user.age = 26;
setUser(user);
```

## Lazy Initialization

If your initial state is expensive to compute, pass a **function** to `useState`:

```jsx
// ❌ This runs on every render
const [data, setData] = useState(expensiveComputation());

// ✅ This runs only on the first render
const [data, setData] = useState(() => expensiveComputation());
```

## Key Takeaways

- `useState` returns `[value, setter]`
- Use functional updates when depending on previous state
- Never mutate state directly — always create new references
- Use lazy initialization for expensive initial values
