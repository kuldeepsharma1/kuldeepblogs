# Unions and Intersections

Union and intersection types are fundamental building blocks for modeling complex data in TypeScript.

## Union Types (`|`)

A union type represents a value that can be one of several types:

```typescript
type Status = "loading" | "success" | "error";
type ID = string | number;

function processId(id: ID) {
  if (typeof id === "string") {
    return id.toUpperCase(); // TypeScript knows it's a string here
  }
  return id.toFixed(2); // TypeScript knows it's a number here
}
```

## Discriminated Unions

The most powerful pattern in TypeScript:

```typescript
type Result =
  | { status: "success"; data: string }
  | { status: "error"; error: Error }
  | { status: "loading" };

function handleResult(result: Result) {
  switch (result.status) {
    case "success":
      console.log(result.data); // TypeScript narrows to success branch
      break;
    case "error":
      console.error(result.error.message); // Narrows to error branch
      break;
    case "loading":
      console.log("Loading...");
      break;
  }
}
```

<Callout type="tip">
  Discriminated unions are the backbone of type-safe state management. Use them for API responses, form states, component props, and more.
</Callout>

## Intersection Types (`&`)

An intersection type combines multiple types into one:

```typescript
type HasName = { name: string };
type HasAge = { age: number };
type Person = HasName & HasAge; // { name: string; age: number }
```

## Key Takeaways

- Unions (`|`) = "either A or B"
- Intersections (`&`) = "both A and B"
- Discriminated unions enable exhaustive type checking
- Type narrowing makes unions safe to use
